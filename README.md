# 🍎 dotfiles-macos – Pomme2T3rr3

This repository contains my personal macOS dotfiles, designed for a minimalist and cohesive development environment inspired by the *NieR: Automata* aesthetic.

## 🧰 Features

- Configurations for `zsh`, `neovim`, `tmux`, `starship`, and more  
- `Brewfile` for quick tool installation with Homebrew  
- Custom terminal color theme: `Nier_Theme.json`  
- Organized dotfiles and aesthetic screenshots

## 🐧 podsays

Check out [podsays](https://github.com/Pomme2T3rr3/podsay), a fun terminal tool I made that displays inspiring quotes with an artistic twist. It's integrated into my terminal setup and featured in one of the screenshots above.

## 🎨 Nier Theme

The `Nier_Theme.json` file defines a dark, elegant color palette inspired by *NieR: Automata*. Compatible with iTerm2, Alacritty, and other customizable terminals.

## 📂 Repository Structure

- `Brewfile` – Homebrew packages and apps  
- `Nier_Theme.json` – Terminal color scheme  
- `config/` – Configuration files for tools (e.g. `nvim`, `tmux`)  
- `screenshots/` – Preview images of the rice  
- `wallpapers/` – Themed wallpapers (optional)
